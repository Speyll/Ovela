Android Signed APK

Android TV & Google TV

The living-room build, with D-pad navigation throughout. The same APK also installs on Android phones.

  • Android 6.0 or newer
  • Install directly from the APK
  • Live TV, films, series, and favourites

webOS Unsigned IPK

LG webOS

Built for LG TVs with webOS and installed through Developer Mode. No custom webOS signing setup is required.

  • Unsigned IPK for Developer Mode
  • Remote-first navigation
  • Optional local API bridge for CORS-blocked providers

Ovela ships with no channels, playlists, or subscriptions. You connect a provider you already have.

Features

Everything you need.
Nothing you don't.

A small, deliberate feature set for everyday viewing.

  • Live, films, and series

    One catalogue for live channels, movies, and episodic series.

  • Xtream Codes & M3U

    Connect the provider and playlist format you already use.

  • Alternate servers

    Configure backup hosts and let Ovela fail over when a server drops.

  • Favourites & progress

    Keep favourites close and pick up where you left off.

  • Built-in player

    Playback controls, subtitles, and stream-format selection in one place.

  • Made for the remote

    D-pad focus, clear edges, and predictable navigation on both platforms.
