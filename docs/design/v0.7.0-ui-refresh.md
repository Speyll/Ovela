# Ovela v0.7.0 webOS UI design

> **Shipped-state note:** the packaged 0.7.0 catalog uses the readable category
> rail, flat Live TV list, and poster grid described in
> [`ovela.md`](ovela.md). The media-stage/hero exploration below is retained as
> design history; some of its selectors and code paths remain unused in the
> shipped shell.

## Release intent

v0.7.0 is a webOS-first living-room interface refresh built around fast remote
navigation, large-catalog performance, and readable 10-foot presentation. The
v0.7 browsing module is a first-class production asset loaded after the stable
webOS core; it owns the new shell while provider, playback, persistence, and
shared normalization primitives remain in their existing modules.

## Primary navigation

The fixed top navigation is:

**Home · Live TV · Movies · Series · Search**

Search appears only on Live TV, Movies, and Series. Settings remains a utility
control at the upper-right. Favorites is not a top-level destination in the new
browse shell; Favorites and existing custom groups appear as virtual categories
inside the relevant media domain. The full Favorites manager remains reachable
from Settings.

## Category rail

The shipped catalog uses a readable vertical category rail rather than the
earlier circular wheel prototype:

- Up/Down moves focus through every provider category; the rail scrolls to keep
  the focused item visible.
- OK/Right or a pointer click commits the focused category.
- Committing a category transfers focus to the first content item once data is
  available.
- Back from content returns to the category rail with the same category and
  scroll position; Back from the rail returns to top navigation.
- The rail renders the full category list; it is not a fixed-size window.

Provider network work begins only when a category is committed.

## Home

Home remains search-free and emphasizes continuation rather than browsing:

- Jump Back In
- Continue Watching Live TV
- Continue Watching Movies
- Continue Watching Series
- Favorite Channels when available

Directional focus stays within Home until the user reaches the upper-most
content region, then Up returns to main navigation.

## Live TV

Live TV is guide-first:

- five visible stations per EPG window
- large station and program typography
- two-hour timeline with 30-minute markers
- full-height current-time line
- short-EPG requests only for the visible five-channel window
- D-pad Up/Down moves one channel
- holding Up/Down pages a complete five-channel EPG window

The physical LG Channel +/- buttons are not relied upon because webOS does not
consistently expose those remote keys to web applications.

## Movies and Series

Movies and Series use an immersive artwork-first browse model:

- category rail at left, visually softened into the media canvas
- provider fanart/backdrops fill the media stage instead of living inside a hero box
- horizontal, vertical, and top opacity gradients blend artwork directly into the page
- title, metadata, description, and actions float over the faded artwork
- metadata is rendered as lightweight inline text rather than bounded pills
- the successful six-column poster rail remains full-width and titleless
- unfocused posters are slightly subdued; focus uses a quick scale/brightness lift and
  a restrained edge glow instead of permanent card borders
- artwork URLs such as `images/noposter.jpg`, null backdrop entries, and invalid
  relative placeholders are rejected before rendering

Series catalog responses already provide `cover`, `plot`, `rating`, genre, release
date, and `backdrop_path`, so Series browsing never needs `get_series_info` merely
to populate its hero. Full series info remains deferred until the user opens the
series detail/episode workflow.

Movies retain lightweight catalog navigation and enrich the hero after a short
dwell with `get_vod_info`. The dwell is deliberately long enough to avoid firing
requests for posters the user is only passing through. Rich movie metadata and
backdrops are cached after the first request.

Backdrop swaps are image-preloaded and cross-faded only after the image has decoded
enough to load. Series also preloads the immediately adjacent backdrops after an
idle pause, keeping D-pad movement responsive without eagerly loading artwork for
the entire catalog.

## Search

Search is launched from the top navigation and scopes only to the currently
committed category. It opens as a webOS-keyboard-safe overlay and never appears
on Home. Search state is retained per media domain until cleared.

## Favorites

Favorites behavior in v0.7 includes:

- virtual Favorites category in Live TV, Movies, and Series
- existing custom favorite groups exposed as compatible virtual categories
- focus preservation when favorite/unfavorite changes cause a re-render
- **Auto-sort A-Z** enabled by default in the Favorites editor
- manual item reordering available when alphabetical auto-sort is disabled

The `favoriteAutoSort` setting is part of normal local settings persistence.

## Provider failure behavior

A failed provider connection must not erase saved credentials. Manual failed
attempts re-render the submitted values without persisting new credentials until
a successful authentication occurs. Explicit Disconnect remains the only normal
UI action that clears saved provider credentials.

## Performance rules

- Category-scoped provider requests only.
- Bounded DOM windows for Live TV and media rails.
- Short EPG cache for visible stations.
- 180 ms debounced/cached movie metadata enrichment with cross-faded backdrop promotion.
- Adjacent Series backdrop preloading only after an idle pause.
- No password or authenticated stream URL logging.
