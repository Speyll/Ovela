# XtreamlyTV 0.7.0

## webOS living-room UI refresh

Version 0.7.0 promotes the extensively TV-tested webOS UI refresh from an
iterative overlay prototype into the repository's production v0.7 release
surface. The release keeps the stable provider, playback, persistence, and
shared-core foundations while replacing the webOS browsing experience with a
more readable, remote-first shell.

### Navigation and categories

- Introduces a fixed top navigation for **Home**, **Live TV**, **Movies**, and
  **Series**, with catalog-scoped Search exposed as a dedicated top-nav action.
- Adds a circular, fixed-center category wheel designed for deterministic
  D-pad and Magic Remote use.
- Routes Back from content to the category wheel and Back from the wheel to the
  main navigation.
- Keeps Favorites out of the top-level navigation and exposes Favorites plus
  compatible custom groups as virtual categories within each media domain.

### Live TV and EPG

- Rebuilds Live TV around a five-channel EPG window with larger station,
  program-title, and program-time typography.
- Adds a two-hour timeline, 30-minute markers, and a full-height current-time
  indicator.
- Keeps short-EPG requests bounded to the visible channel window.
- Adds fast full-page EPG movement by holding D-pad Up/Down while preserving
  normal single-channel movement on short presses.

### Movies and Series

- Adds a six-column poster rail that fills the browse area without redundant
  card-title text.
- Reworks the browse surface around provider fanart: full-stage backdrops fade
  horizontally, vertically, and into the top chrome instead of being constrained
  by a visible hero container.
- Floats title, metadata, plot, and actions directly over the artwork with
  lightweight inline metadata and no description divider.
- Makes poster focus faster and quieter with brightness/opacity changes, a small
  scale lift, and a restrained focus glow rather than permanent card boundaries.
- Rejects known missing-art placeholders and null backdrop entries before render.
- Cross-fades preloaded backdrops to avoid flashes while moving through a catalog.
- Debounces movie `get_vod_info` enrichment to avoid detail requests for items the
  user only passes over, while caching rich results once fetched.
- Uses rich `get_series` catalog metadata/backdrops directly and keeps the much
  larger `get_series_info` payload deferred until the selected series is opened.
- Preloads only the neighboring Series backdrops after an idle pause for smoother
  D-pad navigation without eagerly downloading an entire category's fanart.

### Search

- Removes the always-visible catalog search field.
- Adds a Search icon to the catalog top navigation and a dedicated pop-out
  search surface scoped to the active category.
- Includes webOS on-screen-keyboard viewport handling so the search control
  remains usable when the LG keyboard opens.

### Favorites

- Preserves focus when favorite/unfavorite actions re-render the current
  catalog.
- Adds **Auto-sort A-Z** to the Favorites editor and enables it by default.
- Allows the existing manual item order when alphabetical sorting is disabled.

### Provider resilience

- Failed reconnects no longer clear saved provider credentials.
- Manual failed attempts retain the submitted values on the provider screen but
  do not persist new credentials until authentication succeeds.

## Platform status

This is a **webOS-first v0.7 release**. Android TV is version-synchronized to
0.7.0 for the monorepo release process but retains the v0.6 product/UI behavior;
a native Android parity pass for the v0.7 webOS browsing model remains future
work.

## Validation

- All webOS JavaScript parses successfully.
- Root, webOS, core-web, and Android package versions are synchronized to 0.7.0.
- Shared core tests pass.
- The webOS release check now validates that the production v0.7 CSS/JS assets
  are present and loaded by `index.html`.
- Extensive physical LG TV iteration covered category focus, EPG scrolling,
  Movies/Series rail sizing, hero readability, Favorites behavior, failed
  provider reconnects, and the Magic Remote search workflow.
